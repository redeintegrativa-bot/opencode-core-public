# OpenCode Terminal Chat

Interface de chat no estilo BotFather que conecta direto ao motor OpenCode.

## Uso

```bash
python3 opencode_chat.py
```

## Comandos

| Comando | Ação |
|---------|------|
| `/help` | Lista de comandos |
| `/status` | Status do agente |
| `/clear` | Limpa a tela |
| `/quit` | Sair do chat |

## Dependências

```bash
pip install rich prompt_toolkit
```
