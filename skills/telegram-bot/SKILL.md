# Telegram Bot

Remote OpenCode interface via Telegram.

## Usage
- `/telegram` — Inicia sessão remota
- Notifications, daemon mode, orchestrator bridge

## Requirements
- Bot token via `TELEGRAM_BOT_TOKEN` env var
- `python-telegram-bot` library
